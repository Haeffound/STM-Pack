# Subway Builder Montréal STM Train Pack

Subway Builder STM-Pack is a mod for the game Subway Builder that adds trains from the Montréal Metropolis. This pack change base-game vehicles only.

This pack also is fully compatible with all the current Beta feature (acceleration curve, diesel train, tram, doors, catenary…).

Light Metro is not changed because it's already the basegame vehicle (just changed the name).
